## 🚀 How to Run the Files

1. Set up a virtual environment:
   ```bash
   python -m venv venv
   source venv/Scripts/activate # Windows
   ```
2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
3. Run any file:
   ```bash
   python day01_variables.py
   ```
